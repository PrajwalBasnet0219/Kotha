Final Capstone Project: Full Stack Web Development Internship
Final Capstone for the React, Node.js and MongoDB internship. The full brief is attached as a PDF. HOW IT WORKS - Each intern chooses their own project idea (the two interns must not build the same project). - The proposal comes first and must be approved before any code is written. - The project must meet every criterion below and cover the coverage matrix topics. - Final submission deadline: 7 December 2026. PROJECT CRITERIA (minimum) - Scope: 2+ user roles, 5+ MongoDB collections, 15+ user stories - Authentication: register, login, logout, forgot/reset password, email verification, access + refresh tokens (jsonwebtoken, bcrypt) - Authorization: role-based access in API and UI, protected routes - CRUD with validation for 3+ main entities (Joi/Zod, React Hook Form) - Server-side search, filter, sort, pagination with indexes - File upload (Multer + Cloudinary or S3) - Email notification (Nodemailer with SMTP, Gmail or Mailtrap) for verification, reset and 2+ key events; in-app notifications - Payment if the idea involves money (Stripe test mode; PayPal, eSewa or Khalti sandbox as alternatives) - Real-time if the idea involves live updates (Socket.IO) - Dashboard with 3+ charts from MongoDB aggregation - One more third-party integration - Security: helmet, CORS, rate limiting, sanitization, env secrets - 15+ automated tests (Jest, Supertest, React Testing Library) - README and API docs (Swagger or Postman) - Deployment (Vercel/Netlify, Render/Railway, MongoDB Atlas) with test accounts per role EVALUATION (100 marks): proposal and design 20, frontend 20, backend 20, database 10, testing and code quality 10, deployment and documentation 10, final demo and Q&A 10. FINAL SUBMISSION CHECKLIST: live URLs and test accounts, GitHub repo with README, updated design documents, Postman or Swagger docs, test report, final report (5-8 pages), 5-minute demo recording, mentor sign-off.
