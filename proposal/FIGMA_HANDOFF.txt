================================================================================
08  MOTION NOTE FOR THE PROTOTYPE
================================================================================
  Figma cannot run shaders, so annotate rather than fake:
    - page transitions: smart animate, 240 ms, cubic-bezier(.22,1,.36,1)
    - drawers and modals: 200 ms, ease out
    - F-04 -> F-05: add a note "a single scan beam sweeps the room as it resolves
      (Grid Scan technique, 900 ms, once)"
    - F-05 -> F-06: note "selection halo 140 ms; dust lifts toward the selection"
    - global: note "film grain 3.5% at 8 fps; lens at the viewport edges follows
      scroll velocity; both disabled under prefers-reduced-motion"
  The real behaviour is specified in Section 7.4 of the proposal, including the
  React Bits reference table and the monochrome adaptation of each technique.
